# Cybersecurity Learning Journey

This repository contains hands-on cybersecurity and networking labs developed as part of my transition into SOC and Blue Team roles. The focus is on practical skills across SIEM monitoring, log analysis, incident investigation, and core networking fundamentals.

Each project is documented with clear objectives, architecture, configuration steps, and validation results to demonstrate real-world understanding rather than theory alone.

---

## Projects

### Splunk SIEM SOC Lab
A self-directed SOC lab focused on endpoint monitoring and log analysis using Splunk Enterprise.

**Key focus areas:**
- Windows Security Events, Sysmon, DNS/HTTP log ingestion
- SPL-based investigations and alert analysis
- Custom field extractions (src_ip, src_port, dst_ip, dst_port)
- MITRE ATT&CK mapping and investigation documentation

Folder: `Splunk-SIEM-SOC-lab/`

---

### Multi-LAN Network Architecture with DHCP-Lab (Cisco Packet Tracer)
Hands-on networking labs designed to strengthen foundational knowledge required for SOC investigations.

**Key focus areas:**
- Multi-LAN network design
- DHCP configuration and troubleshooting
- IP addressing, subnetting, and routing
- End-to-end connectivity validation

Folder: `Multi-LAN Network Architecture with DHCP-lab/`
